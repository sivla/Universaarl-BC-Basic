# Loesungsdesign: BC Basic Einrichtung

Das Lösungsdesign verbindet die kanonische Projektsimulation mit den drei Confluence-Wissensräumen, den UABC-Tickets, den Evidence-Ketten und dem filesystem-basierten Twin-Katalog. Kundenspezifische Entscheidungen bleiben in BC Basic; Spectra liefert nur den generischen Produktvertrag.
