# Lieferplan: BC Basic Einrichtung

Die Migration wird als ein lokaler, nachvollziehbarer Lieferblock ausgeführt: aktive Story transformieren, Provenienzmatrix erzeugen, Export und Index regenerieren, Validatoren und Negativtests ausführen, OpenSpec/Deutsch/Governance prüfen und erst danach den lokalen Commit erstellen. Es gibt keine Live-Jira- oder Remote-Aktion.
