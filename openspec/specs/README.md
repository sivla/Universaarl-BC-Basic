# Freigegebene Spezifikationen

Dieser Ordner enthaelt nur freigegebene normative Spezifikationen. Der Blueprint v0.1 ist noch nicht freigegeben; seine Requirement-IDs werden derzeit aus dem aktiven Change als `proposed` aufgeloest. Dauerhafte strukturierte Architektur- und Capability-Artefakte liegen bereits an stabilen Pfaden, bleiben bis zur menschlichen Freigabe jedoch ebenfalls `proposed`. Die Aufloesungsregeln stehen unter `governance/reference-lifecycle.yaml`.
